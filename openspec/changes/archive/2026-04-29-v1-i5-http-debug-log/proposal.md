# proposal: v1-i5 http debug log

## Why

При ошибках авторизации и сетевых проверок пользователю сложно быстро понять, какие именно runtime-параметры и заголовки ушли в API.
Нужен локальный debug-лог HTTP-вызовов без вывода секретов в консоль и без изменения default-поведения.

## What Changes

1. Добавить опциональный debug-лог HTTP-вызовов для `doctor` и `run`.
2. Включать лог только при явном env-флаге `ANON_HTTP_DEBUG=true`.
3. Записывать лог в `<workspace>/.anonym/http-debug.log`.
4. Маскировать чувствительные заголовки (`Authorization`) перед записью.
