# proposal: v1-i1 foundation preflight discovery

## Контекст

Для `v1` согласован итерационный workflow: каждая итерация должна давать законченный и тестируемый результат. На старте `openspec/changes/` не содержит активных feature-пакетов.

## Цель итерации

Собрать безопасный baseline, который позволяет:
- проверить готовность окружения через `anonym doctor`;
- безопасно обнаруживать файлы через `anonym scan`;
- просматривать локальную очередь через `anonym list`;
- исключить неявную отправку файлов в API на этой итерации.

## Объем итерации (in scope)

1. Preflight в `doctor`:
   - проверка конфигурации и приоритета источников;
   - проверка boundary/ACL;
   - проверка секретов и доступности API.
2. Discovery в `scan`:
   - обход только в пределах `raw_path`;
   - path hardening (anti-traversal, anti-symlink/reparse, anti-ADS);
   - формирование локального состояния.
3. Просмотр очереди в `list`:
   - детерминированный вывод `id/path/status`;
   - отсутствие PII в идентификаторе.

## Вне итерации (out of scope)

- `anonym run` и отправка в `POST /v1/tasks/file_anonymization`;
- обработка контрактов результата анонимизации;
- финальные статусы после отправки (`sent/succeeded/failed`) как рабочий runtime-поток.

## Критерии приемки итерации

1. `anonym doctor` блокирует небезопасные конфигурации и выдает проверяемые ошибки.
2. `anonym scan` индексирует только допустимые файлы внутри `raw_path`.
3. `anonym list` показывает локальную очередь без утечки PII.
4. В `scan/list` отсутствуют сетевые вызовы отправки в API.
