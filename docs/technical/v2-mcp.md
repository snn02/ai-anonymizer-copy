# v2 mcp

## Цель

Добавить MCP-обертку поверх trusted-core CLI без изменения security-модели `v1`.

## Принцип интеграции

- MCP-слой не обходит trusted-core и не получает прямой доступ к raw.
- Все проверки безопасности остаются в ядре.
- MCP выступает как транспорт/интерфейс вызовов.

## Границы ответственности

## Trusted-core

- Проверки boundary/path/security.
- Интеграция с API.
- Запись результата и аудит.

## MCP-слой

- Преобразование MCP tool-вызовов в операции trusted-core.
- Нормализация сообщений для клиентов (OpenCode, Claude и др.).

## Дополнительные требования `v2`

- Документированный lifecycle секретов: rotation/revocation/compromise response.
- Расширенные эксплуатационные сетевые политики (включая proxy-правила при необходимости).
- Диагностика ошибок на стыке MCP и CLI без утечки чувствительных данных.
