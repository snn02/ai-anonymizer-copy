# release

## Стратегия релизов

- Версионирование по релизным этапам проекта (`v1`, `v2`).
- Для каждой версии есть `docs/versions/<version>/plan.md` и `action-log.md`.

## Артефакты поставки

- Бинарник `anonym` для:
  - Windows (`amd64`, при необходимости `arm64`);
  - Linux (`amd64`, при необходимости `arm64`);
  - macOS (`arm64`, при необходимости `amd64`).

## Процесс выпуска

1. Проход release gate (`p0` pass).
2. Сборка бинарников через `goreleaser`.
3. Публикация артефактов и notes.
4. Обновление пользовательской и версионной документации.

## Политика отката

- При критическом дефекте выпуск блокируется или откатывается на последний стабильный релиз.
- Причина и действия фиксируются в `docs/versions/<version>/action-log.md`.
