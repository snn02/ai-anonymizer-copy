# configuration

## Цель

Единая конфигурация для запуска trusted CLI без хранения секретов в репозитории.

## Конфигурационные группы

1. Пути:
  - `raw_path`
  - `output_path`
2. API:
  - `api_base_url`
  - `partner_id`
  - `fields` (по умолчанию)
3. Лимиты:
  - `max_file_size`
  - `max_pages`
  - `request_timeout`
  - `max_parallel_runs`
4. Аудит:
  - `audit_retention_days`
  - `hmac_key_id`

## Правила конфигурации

- Секреты (API key и аналогичные) живут только в OS secret store.
- Конфиг валидируется на старте и в `doctor`.
- Небезопасные значения блокируют рабочие команды.

## Приоритет источников

1. Явные флаги команды.
2. Переменные окружения.
3. Локальный конфиг-файл.

Если есть конфликт, применяется источник с более высоким приоритетом.
