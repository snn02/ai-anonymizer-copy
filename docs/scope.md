# scope

## Назначение

Границы инструмента безопасной анонимизации файлов для ИИ-IDE.

## Что в scope

- Trusted sidecar CLI как единая точка отправки в корпоративный API.
- Пользовательский поток `scan -> list -> run` с явным запуском отправки.
- Сохранение анонимизированного результата в workspace проекта.
- Подготовка MCP-обертки над тем же CLI-ядром.

## Что вне scope

- Деанонимизация на текущем этапе.
- Неявная автоматическая отправка файлов watcher-ом.
- Автоматическое удаление/перемещение raw-файлов.

## Неподвижные ограничения

- `raw_path` расположен вне workspace IDE.
- IDE не должна иметь доступ к чтению raw-файлов.
- Только sidecar CLI имеет доступ к raw и сети корпоративного API.
- Секреты не сохраняются в файлах проекта и не попадают в логи.

## История scope по версиям

- `v1`: sidecar CLI (`scan`, `list`, `run`, `doctor`), только анонимизация.
- `v2`: MCP-обертка над trusted-core CLI без изменения security-модели.
