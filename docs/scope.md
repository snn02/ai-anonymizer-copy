# scope

## Назначение

Фиксирует стабильные границы проекта. Этот документ не ведется как журнал прогресса.

## В scope

- Trusted sidecar CLI как единая точка работы с API анонимизации.
- Пользовательский поток `scan -> list -> run` с явным запуском отправки.
- Сохранение только анонимизированного результата в workspace.
- MCP-обертка поверх того же trusted-core CLI (этап `v2`).

## Вне scope

- Деанонимизация.
- Неявная отправка файлов watcher-ом без команды пользователя.
- Автоматическое удаление/перемещение raw-файлов.

## Неподвижные ограничения

- `raw_path` находится вне workspace IDE.
- IDE не читает raw-файлы напрямую.
- Доступ к raw и сети API имеет только sidecar CLI.
- Секреты не хранятся в проектных файлах и не попадают в логи.
