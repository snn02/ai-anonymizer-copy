# v2 plan

## Цель версии

Добавить MCP-обертку над trusted-core CLI без изменения security-модели v1.

## Требования v2

- MCP-интерфейс поверх существующих команд/операций CLI.
- Совместимость с подходом «raw вне workspace IDE».
- Подключение дополнительных ИИ-клиентов через MCP tool-интерфейс.
- Требования безопасности v1 полностью сохраняются и переиспользуются.
- Провести анализ override-флагов для `run` (`--fields`, `--tags`, `--tags-numeration`) и зафиксировать решение по контракту CLI/MCP (поддерживаем/не поддерживаем/альтернативный механизм).

## Усиления, которые добавляем в v2

- Формализованный операционный lifecycle секретов:
  - регламент ротации;
  - регламент отзыва;
  - регламент действий при компрометации.
- Расширенная сетевая политика для эксплуатационного контура (включая proxy-правила при необходимости).
- Дополнительные проверки и диагностика на стыке MCP и CLI.

## Критерии приемки v2

1. MCP-поток работает поверх CLI.
2. Граница доступа к raw соблюдается так же, как в v1.
3. Диагностика ошибок остается понятной и без утечек чувствительных данных.
4. Усиления по секретам и эксплуатации задокументированы и проверяемы.
