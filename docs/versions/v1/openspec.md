# v1 openspec

## Статус

Feature-спеки для v1 пока не создаются до согласования полного workflow разработки.

## Где будут лежать артефакты после согласования

- Активные изменения: `../../../openspec/changes/`
- Закрытые изменения: `../../../openspec/archive/`

## Правило

После согласования workflow каждая фича v1 оформляется отдельным change-пакетом в OpenSpec.
